title: Smart Campus - Smart Access Control for Educational Institutions
description: "Built an IoT-based access-control case study connecting ERP approvals, secure APIs, and physical gate infrastructure for educational institutions."
date: 2026-04-03
tags:
  - IoT
  - Systems Analysis
  - ERP Integration
  - Access Control

role: Systems Analyst / Associate Product Manager
context: Smart Campus is an educational-management platform, and this project extended it with an IoT module for student exits, returns, and visitor entry management in real-world institutions.
goal_metrics: Create reliable real-time visibility, connect ERP approvals to physical gate actions, reduce manual coordination, and define a deployable operational unit for pilot rollout.
discovery: The product challenge lived across business flows, hardware, connectivity, permissions, and field behavior, so analysis covered both system logic and installation constraints.
options_tradeoffs: Multiple identification and controller options were compared based on cost-benefit, reliability, integration effort, security, response time, and maintenance practicality.
execution: Defined requirements, modeled flows and statuses, specified secure ERP-to-controller integration, translated hardware constraints into product decisions, and supported field pilot deployment.
results: The solution created accurate entry and exit monitoring, tighter operational control, better visibility into student presence, and a scalable base for rollout to additional institutions.
learnings: Strong systems analysis in hybrid hardware-software products means shaping the process, the API, the installation unit, and the field fallback behavior together.
